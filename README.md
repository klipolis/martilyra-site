# Máté Domokos oldala

A matedomokos.hu magyar nyelvű, Markdown-alapú statikus archívuma.


A rendszer felépítéséről, a WordPress és a GitHub Pages összehasonlításáról, valamint az archívum statisztikáiról a [rendszerismertetőben](./docs/README.md) olvashatsz. A változások összefoglalója a [változásnaplóban](./docs/CHANGELOG.md) található.
